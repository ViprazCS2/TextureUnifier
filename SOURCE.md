# Source Availability

Texture Unifier is distributed with its C# source code in the release package.

When built with `build.ps1 -Package`, the archive includes a `source` folder containing:

- `src/` with the mod source files
- `TextureUnifier.csproj`
- `build.ps1`

This is included so players can inspect what the code mod does even when Paradox Mods has not reviewed the package yet.

The security/source transparency notes are in `SECURITY.md`.
