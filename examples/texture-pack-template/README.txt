Texture Unifier texture pack template

Copy this folder into:

%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\ModsData\TextureUnifier\Packs

Rename the folder to your pack name, or press Options > Texture Unifier > New texture folder and use the folder that opens.

You can also add your own files manually with these names:

- Grass_BaseColor.png
- Grass_Normal.png
- Dirt_BaseColor.png
- Dirt_Normal.png
- Cliff_BaseColor.png
- Cliff_Normal.png
- Road_BaseColor.png
- Road_Normal.png
- Sidewalk_BaseColor.png (optional, requires Change sidewalks)
- Sidewalk_Normal.png (optional, requires Change sidewalks)
- Gravel_BaseColor.png
- Gravel_Normal.png

Optional road-wear overlay files:

- RoadWear_BaseColor.png
- RoadWear_Normal.png

After adding files, restart Cities: Skylines II or let Texture Unifier reload them during its normal terrain and material passes.

Sidewalk textures are optional. Enable Change sidewalks in advanced options if you want Sidewalk_BaseColor.png and Sidewalk_Normal.png to apply.
Parking-lot road surfaces use Road_BaseColor.png and Road_Normal.png. There is no separate parking-lot texture file because CS2 stretches that UV layout by design.
